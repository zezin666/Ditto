Settings — dark

Default 900 × 640. Native title bar; left navigation 208; content max 720; cards use the Fluent surface/border tokens.

  1. Window: 900 × 640 logical px, radius 8, 1 px border, dialog shadow; native frame, optional Mica on Windows 11.
  2. Title bar: 32 px native system frame; app icon 14; title 12; window controls 46 × 32.
  3. Navigation: 208 px; items 40 high, radius 4, icon 16 + label 14/20; selected uses selection + 3 px accent bar.
  4. Page header: 64 px; title 20/28 semibold; description 12/16 secondary; content padding 24.
  5. Card: radius 8, 1 px border, padding 16; section title 14/20; helper 12/16.
  6. Field row: label 156 px (14/20); control column flexible; row min 44; gap 16.
  7. Segmented control: 32 px high; 4 segments; selected uses selection fill + accent text; keyboard focus ring 2 px.
  8. Switch: 40 × 20; knob 14; on uses accent fill; label/description adjacent.
  9. Primary button: 32 px high, radius 4, accent fill + onAccent text; secondary uses surface + border.
  10. DPI/tokens: all sizes are logical px; generated from design/tokens.json; no hardcoded colors.
The settings window is created on demand and destroyed on close. No WebView2 process exists at idle; closing the window releases the WebView2 tree.

Data page inset

The Data page is the management surface: search/filter, preview, edit, delete, move to group, pin, and assign a copy buffer. The popup remains the daily fast path.

The table is virtualized for large histories. Preview shows escaped text or a validated image; it never renders active HTML/RTF.

Interaction notes

  • Every control is keyboard reachable; focus ring 2 px.
  • Writes are validated by the core; invalid values do not partially apply.
  • Language, data root, and autostart path changes show a restart banner.
  • Destructive actions require confirmation; backup before restore/import.
