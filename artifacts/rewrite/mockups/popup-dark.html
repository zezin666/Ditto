Popup — dark

Default state. The list is virtualized: 10 visible rows × 36 px; only visible rows + 3 overscan are drawn.

  1. Window: 420 × 480 logical px, radius 8, 1 px border, Fluent shadow (0 8 16).
  2. Title area: 40 px; 16 px app icon; title 14/20 semibold; icon buttons 32 × 32 hit targets (30 px visual); pin/settings/close.
  3. Breadcrumb: 32 px; back 24; 13/18 semibold; count 11/14; chevron opens the group flyout.
  4. Row pitch: 36 px; inset X 4, Y 2; radius 4; selected fill; focused row gets a 2 px inset focus ring.
  5. First-ten badge: 18 × 18, radius 4, 11/14 semibold; index gutter 28 px.
  6. Text: 13/18 regular; meta 11/14 secondary; ellipsis; no unexpected row expansion.
  7. Badges: pinned glyph 14 (caution); pasted check 14 + 3 px left bar (success); copy buffer chip 18 × 18.
  8. Image: 32 × 32 thumbnail, radius 4, 1 px border; full image in the preview pane.
  9. Search: 48 px container; 32 px field, radius 4; 2 px focus ring; IME-aware; bottom position preserved.
  10. Count: 11/14 secondary; progress indicator replaces it after 150 ms for slow queries.
State is never color-only: pinned has a pin glyph, pasted has a check and a left bar, copy buffer has a B# chip. High contrast replaces brand colors with system colors.

Preview state

F3 toggles the preview. It is docked above the search, 160 px default (min 96, max 45% of content). On short popups it replaces the list and keeps the search visible.

  1. Preview pane: 160 px, padding 12, 1 px top border; text 12/16; image fit; color swatch 48; files show names only.
  2. Actions: Copy, Paste, Copy plain text, Open (files), Close. Esc closes the preview before the popup.
  3. No content execution: HTML/RTF are shown as escaped text; no live webview, no scripts, no remote images.
The popup never renders active HTML. Preview is text or a decoded image; file paths are displayed, not executed.
