# T2 New Strings

T2 does not edit `Debug/Language/English.xml`. T5 should merge these keys at
integration time, preserving the exact key names and English defaults.

| Key | English default | Use |
|---|---|---|
| `BackTooltip` | `Back` | Group breadcrumb back button tooltip |
| `SystemMenuTooltip` | `Menu` | Quick-paste system menu tooltip |
| `OptionsTooltip` | `Options` | Bottom-bar options button tooltip |
| `NoResultsTitle` | `No matching clips` | Search empty-state title |
| `NoResultsHint` | `Try a different search or clear it to see all clips.` | Search empty-state hint |
| `ClearSearchAction` | `Clear search` | Search empty-state action |
| `NoStarredClipsHint` | `Star clips to keep them handy here.` | Starred-only empty-state hint |
| `ClearFilterAction` | `Clear filter` | Starred-only empty-state action |
